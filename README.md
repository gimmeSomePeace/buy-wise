# BuyWise

BuyWise — backend-приложение для планирования покупок в нескольких магазинах.

Приложение позволяет хранить информацию о магазинах, товарах и предложениях
магазинов, а также формировать план покупки корзины с учётом цен в разных
магазинах.

## Возможности

На текущем этапе реализована базовая работа с:

- товарами;
- магазинами;
- предложениями магазинов;
- корзиной;
- количеством товаров в корзине;
- планированием покупок.

Проект постепенно расширяется, поэтому API и внутренняя архитектура могут
изменяться.

## Архитектура

Проект представляет собой multi-module Gradle-проект.

Основные модули:

```text
buy-wise/
├── app/
├── domain/
├── application/
├── infrastructure/
└── web/
```

- Domain содержит предметную область и бизнес-правила приложения.
- Application содержит application-level логику и use case'ы. 
- Infrastructure содержит реализации инфраструктурных абстракций.
  В частности:
  - JPA entities;
  - Spring Data repositories;
  - реализации domain/application repositories;
  - взаимодействие с PostgreSQL;
  - persistence-related mapping.
- Web содержит HTTP API приложения.
  Здесь находятся:
  - controllers;
  - request/response DTO;
  - HTTP-specific mapping;
  - обработка ошибок;
  - ControllerAdvice;
  - OpenAPI-документация.

Web не содержит бизнес-логику — он преобразует HTTP-запросы в вызовы
application use case'ов и результаты use case'ов в HTTP-ответы.
- App является composition root приложения. Именно здесь собираются зависимости всех модулей и находится Spring Boot
application.
## Статус проекта

Проект находится в разработке.

Текущая версия представляет собой первую рабочую версию приложения и служит
основой для дальнейшего развития функциональности, API и архитектуры.
